# СЫЗЫМ — сайт проекта

Статический сайт для GitHub Pages: загрузите все файлы в корень репозитория.

## Страницы
- `index.html` — Главная: тема гранта, баннер калькулятора, преимущества, о проекте, новости, контакты
- `calculator.html` — баннер, описание калькулятора со схемой «что к чему относится», калькулятор (несущая способность / подбор армирования), о методике, контакты с формой заявки
- `about.html` — О компании
- `fsi.html` — Поддержка ФСИ
- `news.html` — Новости (раскрывающиеся блоки; ссылка вида `news.html#company-registration` открывает нужную новость)
- `contacts.html` — Контакты и форма заявки (открывает письмо в почтовом клиенте)

## Общие файлы
- `styles.css` — стили всех страниц
- `site.js` — меню, анимации, схема стыка, раскрытие новостей по ссылке, форма заявки
- `calc.js` — калькулятор (сжатая версия; исходник хранится отдельно и на сайт не загружается)
- `coefficients.json` — служебная таблица калькулятора
- `sizym-logo.svg`, `fasie-logo.png` — логотипы
- `img/news/` — фотографии для новостей

## Как добавить новость
Новости в `news.html` сгруппированы по кварталам (`<div class="quarter">`). Новость — это блок `<details class="dd" id="...">…</details>`:
скопируйте похожий блок, поменяйте id, заголовок и текст.
Фото кладите в `img/news/` (JPG до 1600 px по ширине) и подключайте блоком `<div class="news-gallery n1">` (n2, n3 — две или три фотографии в ряд).
Чтобы новость появилась на главной, добавьте карточку `<a class="news-card has-img" href="news.html#id">` в `index.html`.
